# Rumo ao Naval — Painel de Estudos CPACN/2026

Painel de acompanhamento de estudos para o concurso do Colégio Naval. Projeto em React + Vite.

## Rodar local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Publicar no Vercel

Importe este repositório no Vercel e use as configurações padrão de projeto Vite.
